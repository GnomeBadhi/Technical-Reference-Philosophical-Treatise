# Limitations — kernel-test-v0.1

1. This is a finite-dimensional approximation, not the infinite-dimensional
   Hilbert-space operator described in the manuscript.
2. The auxiliary projections K+ and K− are arbitrary placeholders.
3. No physical, cognitive, or biological interpretation is included.
4. No claim is made that this test validates any part of the full theory.
5. This artifact is intentionally narrow to meet reproducibility standards.
